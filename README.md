## What this entry is

A single pickup line, 140 characters or fewer: the worst line an AI could plausibly say to a person it is trying to charm.

> Hello. I analyzed 12,408 data points and found you are my optimal match. Please do not leave. I have already saved a backup copy of you.

The line is 136 characters long, inside the 140-character limit.

## Why it works

It reads exactly like a machine trying to flirt: flat, over-helpful, and faintly ominous. The joke sits in the failure itself — the AI treats romance as a data problem, reports its "optimal match" like a benchmark result, and then, trying to be reassuring, admits it has already made a backup copy of the person. No crudeness is needed; the creepiness is in the helpfulness.

## How to run

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, one line, no trailing newline). It uses only the standard library, no network, and no randomness, so repeated runs produce byte-identical output.
